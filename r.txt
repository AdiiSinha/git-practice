Build/refine the "Commitments" page of my existing Workday Copilot application.

IMPORTANT:
Do not create a separate application.

The purpose of this page is:

"Understand what I have promised, what is due, what is at risk, and what I should follow up on."

==================================================
1. CORE CONCEPT
==================================================

Create an AI-powered "Commitment Intelligence" page.

The page analyzes the employee's REAL Microsoft Outlook email data and identifies commitments/promises made by the employee.

Examples:

"I will send the report tomorrow."
"I'll review this by EOD."
"I can share the document this afternoon."
"I'll get back to you on Friday."
"I will follow up with the client."

These should become trackable commitments.

Normal conversational messages such as:

"Thanks for the update."
"How are you?"
"Looks good."
"Important testing part 2"

should NOT automatically become commitments.

The page should combine:

Microsoft Graph email data
+
AI semantic understanding
+
deadline extraction
+
completion detection
+
priority/risk analysis

to create a useful commitment tracker.

==================================================
2. DATA SOURCE
==================================================

Use REAL Microsoft Graph Outlook data.

- Sent emails
